# 网易云内置播放与自定义 API

## 播放歌单

双击根目录 `start-moondog.cmd`。在“设置 → 网易云音乐”完成官方扫码登录，打开歌单，点击“播放整个歌单”或点击某一首歌的名称。播放器右栏提供暂停、继续、上一首、下一首、进度拖动和停止；歌曲结束后自动播放下一首。音源地址按曲目即时获取，退出账号会停止并清空队列。

桌面播放不需要安装或登录 `ncm-cli`。音源仍按网易云账号会员、购买和地区版权权限提供：不可播放曲目会提示原因，自动续播时可跳过不可用曲目；只有试听权限时标注“试听”。这次没有加入文件下载和音乐库同步。

音乐在 Moondog 内部播放，打开电脑上的网易云客户端不会接管 Moondog 的播放。音频节点返回 403、加载失败或超过 4 秒仍未开始时，播放器自动尝试网易云的备用 CDN，保留账号授权的音源路径、签名和播放进度。修复来自本机真实账号的复现：原节点拒绝访问，同一授权音源的备用节点正常返回 MP3。

## 中转站与自定义模型

打开“设置 → 模型”，向下找到“自定义 API / 中转站”。

| 字段 | 填写方法 |
| --- | --- |
| API 地址 | 服务商提供的接口地址，例如 `https://gateway.example/v1`；也可粘贴完整的 Chat Completions、Responses 或 Messages 操作地址，应用会规范化 |
| API Key | 该站点的密钥；保存后不回显，原地址留空可保留已保存密钥 |
| 模型 ID | 按中转站提供的实际 ID 填写，可包含自定义别名和斜杠 |
| API 协议 | 普通 OpenAI 兼容中转优先选 Chat Completions；也可选 Responses 或 Anthropic Messages |
| 上下文 / 输出 token | 根据站点实际模型能力填写；默认上下文 128000、输出 4096，不代表所有模型均支持该额度 |

点击“保存并使用”后，会将当前模型切换到该接口，并在重启后保留。对话与音乐画像构建共用这套配置。“测试连接”向已保存的站点发送一个简短模型请求；保存本身不发送请求。修改地址后需重新填写密钥，避免把旧站点的密钥转发到新站点。

HTTPS 中转站和本机 HTTP 服务均可使用。本机服务地址可填 `http://localhost:1234/v1`。聊天和测试连接均由核心进程发起，渲染界面没有直接请求中转站的权限。错误信息不展示上游原始响应或密钥。

模型需支持所选协议；音乐代理功能还需要该模型支持工具调用。“测试连接”验证认证和基础流式响应，站点对工具调用、推理参数及额度的支持以实际服务为准。

## 本次验证

实际 Electron 窗口使用虚构账号、本地生成的 WAV 音频和本机模拟中转站完成以下操作：歌单播放、暂停/续播、进度跳转、前后切歌、歌曲结束自动续播、保存自定义站点、测试连接、通过该站点发送真实流式聊天请求。页面未产生 JavaScript 错误。

76 项相关测试全部通过，三种协议分别验证了实际请求路径、认证头及流式响应解析。测试没有使用真实网易云账号、真实中转密钥或付费 API。相关回归日志及截图位于 Git 忽略的 `outputs/netease/`。扩展的模型回归为 107 项中 89 通过、18 失败，失败均为原有 Windows 的目录 fsync 和符号链接权限相关问题，失败名称与原版对照一致。

2026-10-24 的 CDN 故障修复另行使用已登录账号取得的真实授权音源，在隐藏、静音的 Electron 窗口验证：`m804.music.126.net` 返回 403 后自动切换到 `m701.music.126.net`，取得 206 音频响应、产生实际 `playing` 事件且播放进度持续前进；暂停、跳转至 20 秒并续播成功。19 项网易云相关测试通过，覆盖拒绝访问、加载超时、备用节点耗尽、保留进度及停止后取消重试。

代码更新后请从菜单“Moondog → 退出”完整退出，再运行 `start-moondog.cmd`。窗口右上角的关闭按钮会隐藏窗口，后台进程仍运行，不能用来加载新版。

提交 PR 前已合入上游 `f364e2e`，服务菜单的网易云入口直接打开内置登录和歌单页。当前扩展检查 94 项中 93 通过；唯一失败为已有的 macOS 终端系统播放器测试，在 Windows 无法运行其 `#!/bin/sh` 的 `afplay` 替身。Electron 构建和隔离桌面复查通过，覆盖新菜单入口、歌单播放与自动续播，以及自定义 API 连接测试和流式对话。
