# Moondog Lunar Record Key Visual

Status: selected by the project owner on 2026-09-02.
On 2026-10-27 it became the key visual; the logo is now the code-drawn SVG in [`../`](../README.md).

This directory contains the selected Moondog picture.
The picture is a square crop of a 1024 x 1536 poster with the `MOONDOG` wordmark.
The poster is no longer in the tree; Git history keeps it at commit `d0f9e0d`.

## Assets

- [`moondog-key-visual-1x1.png`](moondog-key-visual-1x1.png) is the centered square picture without a wordmark.
  It was named `moondog-logo-1x1.png` until 2026-10-27.
- [`EXPORT_MANIFEST.md`](EXPORT_MANIFEST.md) records dimensions, checksums, and export provenance.

## Design logic

The central dog profile is constructed from dense horizontal data bars.
The dog wears headphones and sits inside a grayscale moon that also reads as a vinyl record.
The headphone earcup and lunar craters deliberately share a concentric-ring grammar.
The stylus entering from the upper-right edge reveals the vinyl interpretation without displacing the moon reading.
The poster keeps the circular symbol and `MOONDOG` wordmark visually separate so the symbol can function independently as a logo.

## Relation to the logo

The logo keeps this picture's dog, headphones, record, craters, and tonearm.
Their shapes were measured from this file, so the logo's outline matches it.
The logo leaves out the paper and the bar mosaic, which stay with this key visual.

## Preservation notes

The poster was a byte-for-byte copy of the selected image.
The square picture is a deterministic crop of that poster and was not regenerated or repainted.
Do not redraw, recolor, add facial features, or replace the concentric crater and earcup relationship without a new design decision.
Selection and repository storage do not by themselves authorize public release or publication.
